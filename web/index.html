What these numbers mean

These are distribution events, not unique users, active installations, or running servers. Repeat downloads, automated builds, caching, and provider counting rules affect the totals. Container pulls and package downloads use different units; the combined count is a convenience measure.

PyPI counts come from PePy, Docker pulls from Docker Hub, and GHCR downloads from GitHub’s public package page. Optional npm sources count completed UTC days from their configured start date. Provider corrections are accepted and flagged; growth is withheld across corrections, configuration changes, stale observations, and missing days.

Growth compares complete observations across 1, 7, and 30 days. History begins when exact collection is enabled; older rounded badges are not reconstructed into exact counts. Each UTC day retains its latest collection attempt.
